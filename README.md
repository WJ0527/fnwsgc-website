# 阔农温室工程材料 - 企业官网

这是一个适用于 GitHub Pages 的静态企业展示网站，包含首页、关于我们、产品中心、联系我们四个页面。

## 部署步骤

1. 在 GitHub 上创建一个新的仓库（例如 `gywsgc-website`）。
2. 将本文件夹内的所有文件和子文件夹上传到该仓库。
3. 进入仓库的 **Settings** > **Pages**。
4. 在 **Branch** 下拉菜单中选择 `main`（或 `master`）分支，目录选择 `/ (root)`，点击 **Save**。
5. 等待几分钟，GitHub 会给出访问链接，通常为 `https://你的用户名.github.io/gywsgc-website/`。
